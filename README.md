# SKULLY: HALL PASS

A complete browser-based school-life simulation built with React, TypeScript, Vite, Phaser 3, and Zustand.

## Run

```bash
cd hall-pass
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production Build

```bash
cd hall-pass
npm run build
npm run preview
```

## Features

- Four-year high-school progression with periods, classes, stats, skills, quests, clubs, items, and friends
- Local autosave and manual save/load
- Reactive campus map powered by Phaser
- Achievements, detention, reputation, weather, announcements, random events, and endings
- Responsive desktop and mobile interface

Save data is stored in browser LocalStorage under `hall-pass-save`.
